# Snesquik - Simple SNES emulator with TUI. 

<img width="1363" height="679" alt="Screenshot_20260802_173827-1" src="https://github.com/user-attachments/assets/499bcb4d-5f62-40e7-9ab9-0bb78f20d95d" />


## Current Features 
- Save states
- SRAM 
- Customizable controls
- Support for the GSU, SA1, DSP, and and the S-DD1 enhancement chips 


## Planned Features 
- Resolution options
- Shaders 
- Gamepad support
